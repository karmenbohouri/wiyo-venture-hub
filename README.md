# Wiyo Venture Hub

Static website (HTML/CSS/JS, single file) rebuilt from the Wiyo Venture Hub Google Sites page, for an academic defence (soutenance).

Pages: Home, Incubation, Youth skills, Coworking, Consulting, About us.

## Run locally

Open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deploy

GitHub Pages: Settings > Pages > Deploy from a branch > `main` / `(root)`.
